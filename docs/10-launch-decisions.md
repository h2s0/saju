# 10. 서비스 출시 결정사항

2026-10-27 기준. **확정:** 모바일 전용, Next.js 사용, 루트 DESIGN.md에 디자인 기준 보관, 생성된 운몽이 이미지를 프롬프트 작업 참조로 사용. 아래 추천안은 사용자 확정·서비스 계약과 구분한다.

## 1. 구현 시작 전에 정할 것

| 결정 | 추천 출발점 | 필요한 판단/완료 근거 | 결정 담당 |
| --- | --- | --- | --- |
| MVP 범위 | 종합사주 1종, 무료 미리보기, 구매·보관함·복원 | 무료/유료 목차·예시 결과·오늘 운세 포함 범위 | 운영자 |
| 가격과 원가 | 기존 990원 가설 검증 | PG 비용+모델/재시도+인프라+지원 비용을 반영한 건당 손익, 월 예산·상한 | 운영자 |
| 가입·복원 | 무료는 비회원, 결제 전에 로그인 | 카카오/이메일 등 수단, 비회원 기록 연결, 기기 변경 복원 | 운영자+개발 |
| 백엔드 | Next.js 서버 API + 관리형 PostgreSQL/Auth + 영속 큐/worker | Supabase 등 공급자, 배포 리전·백업·실행시간·비용 비교 | 개발+운영자 |

| 재열람·수정 | 저장된 구매 결과 재열람, 입력 수정 시 기존 결과 보존 | 기간, 수정 입력의 재구매 여부, 상품 개정 시 기존 구매자 처리 | 운영자 |

## 2. 실제 결제 공개 전에 정할 것

| 결정 | 정해야 할 내용 | 완료 근거 |
| --- | --- | --- |
| 운영 주체·정책 | 사업자 정보, 판매 대상 국가/연령, 이용약관·환불/청약철회·개인정보 문구 | 실제 운영 조건과 PG 계약에 맞는 검토 완료. 이 문서는 법적 요건의 확정 목록이 아님 |
| 데이터 수명 | 비회원 입력/회원 프로필/풀이/주문/분석 로그 각각의 보관 기간, 삭제·계정 탈퇴, 거래기록 보존의 구분 | 데이터 목록·기간·삭제 작업·백업 만료 및 복원 후 삭제 재적용 절차 |
| 외부 처리 | 모델에 보낼 최소 필드, 해외 처리/보관 여부, 공급자 학습·로그 설정 | 공급자 계약/설정 확인. 가능하면 이름·원시 출생정보 대신 계산 특징 전달 |
| 비용·남용 방어 | 비회원 생성 한도, 계정/네트워크 제한, 모델 토큰·재시도 예산, 비용 상한 시 안내 | 부하·제한 테스트 및 비용 알림 |
| 장애·복구 | 결제 불명 상태, 승인 후 생성 실패, 재시도 상한, 지원/환불 처리 시점 | 실제 복원 테스트, 재처리 도구, 담당자·연락 경로 |
| 운영 도구 | 주문 조회·PG 대사·환불·권한 복원·실패 작업 재처리·삭제 요청 | 최소 관리자 화면 또는 인증된 운영 도구, 권한 분리·감사 기록 |
| 배포·복원 | 도메인, 배포 계정, 환경/키 분리, DB 백업, 복구 시간·손실 허용 범위 | 스테이징 검증·백업 복원 실험·롤백 절차 |
| 고객지원 | 문의 주소, 응대 시간, 분쟁/환불 담당 | 사용자가 주문을 특정하고 진행 상황을 확인할 경로 |
| 디자인·권리 | 운몽이 마스터 확정, 서체·캐릭터·상표 사용 권리, 모바일 접근성 | 에셋 승인 기록·라이선스·실제 기기 QA |
| 측정·알림 | 최소 이벤트, 오류·생성 지연·결제 불일치 알림 | 개인정보 없는 대시보드와 수신 담당자 |

## 3. 이후로 미룰 수 있는 것

궁합·추가 SKU, 친구 초대/합동결재, 네이티브 앱, 실시간 AI 상담, 별도 대규모 API 서버. 초기 결제·정확도·복원·운영을 검증한 뒤 확장한다.

## 4. 추천 결정 순서

1. 상품 목차·무료 범위·가격 가설과 로그인/복원 정책.
2. 계산 정책·검증 데이터·모델 원가 시험.
3. DB/Auth/큐/worker/배포와 PG 선택.
4. 재열람·환불·보관/삭제·지원 운영 규칙.
5. [출시 게이트](08-analytics-and-qa.md)의 결제·복원·보안·디자인·운영 검증.

확정될 때 [결정 기록](09-competitor-research-and-decisions.md)에 상태를 남기고 해당 도메인 문서에 반영한다. 추천안만으로 외부 가입·유료 플랜·운영 배포를 완료했다고 간주하지 않는다.
