# 03. 모바일 화면 적용 가이드

색상·타이포·간격·컴포넌트·모션·접근성의 단일 기준은 루트 [DESIGN.md](../DESIGN.md)다. 이 문서는 홈 화면 적용 예시만 보관한다. 수치 변경 시 DESIGN.md를 먼저 수정한다.

## 1. 홈 화면 모바일 레이아웃 스펙

```text
┌─────────────────────────────┐
│ ☁ 천명록             [내 기록] │ ← 앱바
├─────────────────────────────┤
│ 하늘 어딘가에 기록된 이야기…    │
│ 오늘도 운몽이가              │
│ 찾아드릴게요!                 │
│                              │
│    [운몽이 + 몽실이 에셋]      │ ← 콘텐츠 외부에서 표정/포즈 교체
│                              │
│ [ 내 운명록 찾아보기 → ]      │
├─────────────────────────────┤
│ 운명록 메뉴                   │
│ [종합사주 · 990원]            │
│ [오늘의 운세 · 무료]          │
│ [연애운 ... 추후 제공]        │
├─────────────────────────────┤
│ 어떻게 열람하나요?             │
│ ① 입력 ② 무료 미리보기 ③ 선택 결제 │
├─────────────────────────────┤
│ [필요 시] 천계 발령장          │
│ 소개/자주 묻는 질문/정책        │
├─────────────────────────────┤
│  홈   오늘 운세   보관함       │ ← MVP 탭
└─────────────────────────────┘
```

- 홈 첫 화면에는 긴 폼을 바로 노출하지 않고 `내 운명록 찾아보기` CTA로 입력 페이지 이동을 기본으로.
- 로딩 중 캐릭터는 짧은 animation만; 이미지 용량 예산과 LCP 고려.
- 390×844에서 첫 CTA 노출이 필수; 작은 320×568 기기에서는 스크롤 가능.

승인된 에셋만 상태에 연결하고, 에셋 키와 프롬프트는 [캐릭터 가이드](04-character-bible.md)를 따른다.
