# 08. 퍼널 측정 · QA · 출시 수용 기준

## 1. 핵심 성공 지표

**북극성 지표 후보:** `주간 유효 운명록 열람자 수` (무료 미리보기를 충분히 읽거나 유료 보고서를 읽은 고유 사용자 수). 결제 전환뿐 아니라 실제 가치 소비를 본다.

| 구간 | 정의 | 지표 예시 |
| --- | --- | --- |
| 방문→홈 행동 | 홈 조회 중 첫 CTA 선택 | Home CTA CTR |
| 입력 시작→완료 | 출생 입력 시작 대비 제출 | Birth form completion |
| 입력→무료 결과 | 유효 입력 중 미리보기 열람 | Preview success |
| 무료 결과→결제 확인 | 미리보기 열람 대비 결제 진입 | Checkout intent |
| 결제 시작→승인 | PG 시작 대비 서버 승인 | Payment success |
| 승인→리포트 열람 | 구매 완료 중 상세 결과 오픈 | Paid consumption |
| 결과→보관함 재방문 | 재열람 비율 | 7d revisit |
| 발령장→공유→가입 없이 생성 | 발령장 생성 대비 링크 열림·새 생성 | Share activation (P1) |

**목표 수치:** 베이스라인 확보 후 설정. 사전 근거 없는 전환율 목표를 가짜 사실로 쓰지 않는다.

## 4. 캐릭터·디자인 QA

- [ ] 원본 참조 없이 AI로 운몽이 새 얼굴 생성하지 않음.
- [ ] 사용자의 `x73.8%, y23.2%` 원본과 같은 머리·관·리본·복장.
- [ ] `alt` 텍스트: 장식/정보 의미에 따라 적용.
- [ ] 이미지 내 글자·버튼을 삽입하지 않음.
- [ ] 카드/텍스트 색 대비, 키보드 포커스, 탭 44px 검증.
- [ ] iOS Safari/Android Chrome에서 safe area, 입력 키보드, 결제 리다이렉트 검증.
- [ ] `prefers-reduced-motion`을 적용한 경우 효과 최소화.

## 5. 윤리적 품질과 콘텐츠 QA

- [ ] 건강·경제·관계에 대해 확정적인 미래 예언 금지.
- [ ] 오행/명식 오류 가능성은 계산 엔진과 QA 테스트로 검증.
- [ ] 태어난 시간 모름은 불확실한 결과를 사용자에게 고지.
- [ ] 유료 상품에서 무료 샘플을 그대로 반복하는 방식 지양.
- [ ] 문장/목차에 모순이 없고 해석이 이용자 상황과 무관하게 악의적으로 단정하지 않음.
- [ ] 사용자에게 실제 '선배 신선'이 개입한다고 허위 인상을 주지 않음.
- [ ] 실제 데이터 없는 리뷰·구매건수·적중률 게시 금지.

## 6. 출시 게이트

1. **정확도 게이트:** 입력/만세력 계산 회귀 테스트 통과.
2. **결제 게이트:** 주문/PG 승인/복원/환불 시나리오 통과.
3. **보안 게이트:** 구매 권한/개인정보 접근·로그 유출 검사 통과.
4. **디자인 게이트:** 캐릭터 에셋 승인, 모바일 단일 컬럼, 접근성 검사.
5. **법적 고지 게이트:** 운영주체/환불/개인정보/이용약관 실제 확정.
6. **모니터링 게이트:** 거래 실패율·리포트 생성 실패율·핵심 퍼널 대시보드.

준비되지 않은 기능은 `Coming Soon`을 연속 노출하기보다 홈에서 숨겨 기대 관리.
