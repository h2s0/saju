# 09. 벤치마킹 메모 및 의사결정 기록

## 1. 확인 기준

- 확인일: **2026-10-27**.
- 사용자가 지정한 공개 사이트의 **접근 가능한 웹 텍스트/초기 페이지**를 기반으로 요약.
- **실제 결제·인증·결과지 내부까지 구매하거나 사용자처럼 사용해 확인한 것은 아니다.** 따라서 내부 상세 결제 플로우는 공개 정보로부터 단정하지 않는다.
- 각 페이지의 구성·가격은 변경될 수 있으므로 구현/출시 직전 재확인.

## 5. 향후 리서치 작업

- [ ] 각 사이트의 실제 휴대폰 화면에서 앱 셸/탭/입력폼 접근성 캡처 및 비교 (로그인·결제 불필요한 범위)
- [ ] 대표 상품의 **결제 전** 화면에서 가격·제공범위·환불 고지 비교
- [ ] 한국의 소액 디지털 콘텐츠 PG 정산·결제수단·실수령액 조사
- [ ] `천명록`, `운몽이` 상표/서비스명·도메인 충돌 확인
- [ ] 외부 만세력 엔진 2개 이상 교차 검증
- [ ] 유저 5~8명을 대상으로 홈 카피/결제/공유 발령장 사용성 테스트
