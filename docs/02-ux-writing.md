# 02. UX 라이팅 가이드 · 화면별 문구 사전

## 1. UX 라이팅 원칙

**공식 성격:** 견습 신선 운몽이는 밝고 성실하지만 아직 조금 어설픈 천계 신입. 사용자를 진심으로 도우려는 캐릭터.

| 속성 | 할 것 | 피할 것 |
| --- | --- | --- |
| 따뜻함 | '괜찮아요', '함께 찾아볼까요?' | 훈계, 위협, 조롱 |
| 신입다움 | '담당 신선님께 여쭤볼게요!' | 전문 지식 없이 단정 |
| 명확성 | '990원 결제하고 상세 보기' | '승인하기'처럼 가격이 숨겨진 버튼 |
| 자연스러움 | 1~2문장, 쉬운 한국어 | 한자/명리학 용어 남발 |
| 신뢰 | '해석이 달라질 수 있어요' | '100% 적중', '운명이 확정됐어요' |
| 존중 | '관계를 돌아볼 실마리' | '연애 실패할 팔자', '당신 때문에' |

### 핵심 어휘 사전

- **천계 운명관리소:** 제품 세계관(고유명사)
- **운명록:** 개인 운세 리포트
- **운몽이:** 주연 견습 신선
- **몽실이:** 동행하는 구름
- **담당 신선:** 상품의 주제별 안내자(실제 인간이 아님)
- **결재:** 세계관상 서류 승인. 금전이 오가는 단계가 아니다.
- **결제:** 실제 유료 결제. 금액 포함해서 표기해야 한다.
- **열람:** 결과를 보는 행위
- **발령장:** 무료 공유 카드
- **합동결재서:** 둘의 재미있는 협업 유형 공유 카드
- '결재 올렸어요' → 연출로 가능, 유료 상품 CTA는 '990원 결제...'로 명시.

## 2. 대표 브랜드 문구 (유지 대상)

| 상황 | 권장 카피 | 용도 |
| --- | --- | --- |
| 슬로건 | **하늘 어딘가에, 이미 기록된 당신의 이야기.** | 브랜드 서정적 문구 |
| 서브 카피 | **당신의 오늘도, 조금은 더 빛나길.** | 로딩·결과 마지막·소셜 |
| 첫 인사 | '안녕하세요! 천계 운명관리소의 견습 신선 운몽이에요!' | 홈 히어로 |
| 탐색 | '잠시만요! 천계 서고에서 운명록을 찾아볼게요.' | 조회 중 |
| 무료 결과 | '제가 먼저 찾아본 기록은 여기까지예요!' | 미리보기 하단 |
| 추가 풀이 안내 | '더 자세한 이야기는 담당 신선님께 여쭤볼게요!' | 유료 상품 유도 |
| 결제 성공 | '담당 신선님이 결재해 주셨어요! 이제 다음 장을 펼쳐볼까요?' | 실제 결제 성공 이후 |
| 결과 끝 | '오늘의 운명도, 앞으로의 이야기도 응원할게요.' | 상세 리포트 마무리 |

브랜드 슬로건은 동화적 표현이며 운세가 실제로 정해져 있다는 보증이 아니다.

## 3. 페이지별 실사용 문자열

### P-01 홈

- H1: `오늘도 운몽이가 운명록을 찾아드릴게요 ☁️`
- Intro: `안녕하세요! 천계 운명관리소에 막 배치된 견습 신선 운몽이에요.`
- Primary CTA: `내 운명록 찾아보기`
- Subcopy: `간단한 정보로 먼저 무료 풀이를 볼 수 있어요.`
- Hero card: `990원으로 내 운명의 다음 장 펼치기`
- Service heading: `어떤 이야기가 궁금하세요?`
- Free service: `오늘의 운세 · 무료`
- Paid service: `종합 사주 · 990원`
- Empty products: `다음 운명록도 열심히 준비하고 있어요!`
- Returning: `다시 오셨네요! 지난 운명록부터 이어 볼까요?`

### P-02 상품

- H1: `나만의 운명록을 펼쳐볼까요?`
- Body: `타고난 기질부터 관계와 앞으로의 흐름까지 차근차근 살펴드릴게요.`
- Included section: `이번 운명록에 담긴 이야기`
- Price label: `종합 사주 상세 풀이 · 990원`
- CTA: `무료 미리보기 시작하기`
- Existing purchaser: `이미 열람할 수 있는 운명록이에요. 다시 읽을까요?`

### P-03 정보 입력

- H1: `태어난 날을 알려주세요`
- Body: `운명록을 찾으려면 몇 가지 정보가 필요해요.`
- Labels: `생년월일`, `양력 / 음력`, `윤달 여부`, `태어난 시간`
- Time unknown: `태어난 시간을 몰라요`
- Help: `시간을 몰라도 진행할 수 있어요. 일부 해석이 달라질 수 있어요.`
- Validation missing: `생년월일을 입력해 주세요.`
- Validation impossible: `존재하지 않는 날짜예요. 다시 확인해 주세요.`
- Validation future: `오늘보다 늦은 생일은 입력할 수 없어요.`
- CTA: `내 운명록 찾아보기`
- Privacy: `입력하신 정보는 풀이 제공을 위해 사용해요. 보관·삭제 기준은 개인정보처리방침에서 확인할 수 있어요.`

### P-04 조회 중

- H1: `천계 서고에서 기록을 찾고 있어요!`
- Variants: `두루마리를 꺼내고 있어요…` / `운명록의 첫 장을 읽고 있어요…`
- Slow state: `조금 더 시간이 필요하네요. 잠시 후 다시 확인해 주세요.`
- Retry: `다시 찾아보기`
- Abort: `홈으로 돌아가기`
- Note: 실제 서버 처리 상태와 맞지 않는 단계별 완료 문구는 표시하지 않음.

### P-05 무료 미리보기

- H1: `찾았다! OO님의 운명록이에요 ☁️`
- Small heading: `운몽이가 먼저 읽어본 이야기`
- Teaser completion: `여기까지는 제가 설명해드릴 수 있어요.`
- Paid teaser: `관계, 재물, 앞으로의 흐름도 조금 더 자세히 궁금하신가요?`
- Helper: `담당 신선님께 여쭤보고 다음 장을 펼쳐드릴게요.`
- CTA: `990원 결제하고 상세 열람하기`
- Secondary: `무료 풀이만 읽을래요`
- Purchased: `이미 열람한 기록이에요. 이어서 읽기`
- Retake: `입력 정보 수정하기`

### P-06 결제 전 확인

- H1: `상세 운명록을 열람할까요?`
- Item: `종합 사주 상세 운명록`
- Price: `결제 금액 990원`
- Inclusion: `성향, 관계, 일·재물의 흐름, 올해의 조언`
- Re-read: `구매 후 보관함에서 다시 읽을 수 있어요.` (실제 접근 정책이 일치할 때만)
- Policy: `결제 전 제공 내용과 환불 안내를 확인해 주세요.`
- CTA: `990원 결제하고 열람하기`
- Back: `지금은 무료 결과만 볼래요`

### P-07 결제 상태

- Pending: `결제 결과를 확인하고 있어요. 잠시만요!`
- Paid: `결제 완료! 담당 신선님께서 결재 도장을 찍어 주셨어요.`
- CTA paid: `상세 운명록 열람하기`
- Fail: `결제가 완료되지 않았어요. 실제 청구 여부를 확인한 다음 다시 시도해 주세요.`
- Cancel: `결제를 취소했어요. 언제든 무료 운명록으로 돌아갈 수 있어요.`
- Unknown: `결제 확인이 지연되고 있어요. 중복 결제하지 말고 내역을 확인해 주세요.`
- Restore: `결제 내역 다시 확인하기`
- Contact: `결제 도움받기`

### P-08 상세 결과

- H1: `승인된 운명록이 도착했어요!`
- Caption: `천계 운명관리소 · 담당 신선 결재 완료`
- Contents: `나의 기질` / `관계에서의 모습` / `일과 재물의 흐름` / `시기별 해석` / `오늘의 작은 조언`
- Reassurance: `운명록은 가능성을 이야기해요. 선택은 언제나 당신의 몫이에요.`
- Footer: `오늘의 운명도, 앞으로의 이야기도 응원할게요.`
- CTA: `보관함에 가기`
- Soft upsell: `다음으로 궁금한 이야기가 있나요?`

### P-09 보관함

- H1: `내 운명록 보관함`
- Empty: `아직 보관된 운명록이 없어요.`
- CTA empty: `첫 운명록 찾아보기`
- Entry: `다시 열람하기`
- Restore: `구매 내역 복원하기`
- Restore fail: `구매 내역을 찾지 못했어요. 결제에 사용한 계정을 확인해 주세요.`

### P-10 오늘 운세

- H1: `운몽이가 가져온 오늘의 한 장`
- Date caption: `YYYY년 M월 D일의 작은 이야기`
- No birth data: `더 개인적인 오늘의 풀이가 궁금하다면 태어난 날을 알려주세요.`
- CTA: `내 운명록으로 더 알아보기`
- Daily note: `오늘은 내 속도대로 가도 괜찮아요.` (예시, 실제 운세 결과와 구분)

### P-11 계정/복원

- H1: `나의 천계 기록`
- Actions: `로그인하기` / `구매 내역 확인` / `보관된 정보 관리` / `내 정보 삭제 요청` / `문의하기`
- Guest warning: `지금 이 기기에서만 확인할 수 있는 기록이 있을 수 있어요. 잃어버리지 않도록 연결 방법을 안내해드릴게요.` (실제 비회원 구조 확정 후 조정)

### P-13 발령장 (P1)

- H1: `천계에서 나의 첫 부서를 정해볼까요?`
- Loading: `어느 부서에 어울릴지 꼼꼼히 살펴보고 있어요!`
- Result: `축하해요! OO님은 인연부의 분위기 담당 신선이에요.`
- Share: `내 천계 발령장 공유하기`
- Friend invite: `친구와 합동결재서 만들기`
- Privacy: `공유 카드에는 이름·생년월일이 자동으로 들어가지 않아요.`

### P-15 합동결재 (P1)

- H1: `두 신선의 합동결재서가 도착했어요!`
- Waiting: `친구가 아직 발령장을 작성하고 있어요.`
- Shared result: `함께할 때 더 빛나는 조합이네요!`
- Invite: `친구에게 초대 링크 보내기`
- Privacy: `친구가 동의한 카드 정보만 함께 보여줘요.`

## 4. 공통 UX 문구

| 상황 | 문구 | 액션 |
| --- | --- | --- |
| 네트워크 오류 | `연결이 잠깐 끊겼어요. 다시 이어볼까요?` | `다시 시도` |
| 예상치 못한 에러 | `앗, 서류가 잠깐 엉켰나 봐요. 다시 시도해 주세요.` | `다시 시도` |
| 서버 장애 | `지금은 운명록을 꺼내기 어려워요. 잠시 후 다시 시도해 주세요.` | `홈으로` |
| 권한 부족 | `이 기록은 아직 열람할 수 없어요. 구매 내역을 확인해 주세요.` | `구매 내역 확인` |
| 공유 링크 만료 | `이 발령장 링크는 열람 기간이 지났어요.` | `내 발령장 만들기` |
| 복사 성공 | `링크를 복사했어요!` | - |
| 저장 성공 | `보관함에 정리했어요!` | `보관함 보기` |
| 삭제 확인 | `이 정보와 연결된 기록을 삭제하시겠어요?` | `삭제` / `취소` |
| 입력 이탈 | `입력하던 내용이 있어요. 나가면 사라질 수 있어요.` | `계속 입력` / `나가기` |

## 5. 결제 유도 문구 A/B 가설

불안·공포나 거짓 한정성 대신 다음 두 개를 비교한다.

- **A (스토리):** '담당 신선님께 여쭤볼게요! · 990원 결제하고 상세 열람'
- **B (가치):** '관계·재물·올해 운세까지 · 990원으로 상세 보기'

각 안의 버튼에는 반드시 가격과 실제 결제의 의미가 드러나야 한다. 이미 결제한 사람에게는 유료 CTA를 노출하지 않는다.

## 6. 한국어 표기 검사

- `결재` = 내부 승인 / `결제` = 돈 납부. **둘을 구분**.
- `운명록` / `천계 운명관리소` / `운몽이` / `몽실이` 철자 고정.
- 명리학 한자 또는 전문 용어는 설명 팝오버로 풀이하고 주요 CTA에는 넣지 않는다.
- 종결형/조사/띄어쓰기 검수, 버튼 텍스트 2줄 초과 금지.
